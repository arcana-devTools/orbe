# Ferramentas do canal Lino

Pedido do dono em 2026-10-14: Orbe, Hermes, Gemini e os mini-agentes continuam o trabalho com o que for grátis e, se houver, projeto aberto no GitHub. Não peça a lista de novo.

## Quando usar

Use quando o trabalho for o canal, o Lino, um corte, uma animação ou uma montagem de vídeo. Vale para este projeto e para os próximos do mesmo canal.

## O que pode usar, sem conta

- ffmpeg, já na máquina: cortar, juntar, muxar voz, exportar mp4.
- HyperFrames, se o Node for 22 ou mais novo: cena em HTML, gravação local. Código em github.com/heygen-com/hyperframes. Não instale na Node 20 e finja que funcionou.
- Synfig, se estiver instalado: animação 2D vetorial. O site syn.by não é o Synfig. O programa é synfig.org.
- OpenCut, no computador do dono: editor aberto, sem marca d'água. Site opencut.app. Código github.com/opencut-app/opencut. Não suba Bun, Docker e banco só para um corte curto se o ffmpeg resolver.

## Só com a conta do dono

Não abra, não gaste crédito e não mande arquivo para o site:

- Higgsfield
- LoreMotion
- ArtCraft (getartcraft.com)
- geração na nuvem do Donkey Cut

Donkey Cut como editor no navegador, na máquina dele, pode. A geração paga, não.

GetCraft (getcraft.com) é marketplace para contratar gente. Não é ferramenta de corte.

## Contas

Já existe um canal no YouTube e um no TikTok. Não poste neles. Não misture o Lino com esse canal.

A história do Lino vai para outra conta, ainda não aberta. Não crie a conta. Não peça senha, cookie nem código. Não publique o episódio até o dono dizer que a conta existe e que aquele arquivo pode subir.

## Não usar

- Não publique. Não poste. Não abra perfil.
- Não use GeeLark para postar, esquentar conta ou cuidar de várias contas.
- Não mande corte, cookie, cofre ou sessão para o 123apps nem para outro site. O corte sai no ffmpeg.
- matchcut.app não é ferramenta do Lino. Não troque o plano por efeito de texto.
- Não copie anime, personagem, nome ou metragem de outro. Estilo próprio, história própria.
- Não recomece um corte que ele já aceitou. Não suba o Lino de nível por conta própria.

## Como proceder

1. Prefira a ferramenta que já está na máquina.
2. Se faltar uma livre e local, diga o nome e o que falta. Não invente instalação.
3. Se a ferramenta pedir login ou crédito, pare e peça a conta. Não crie chave.
4. Entregue o arquivo. Não publique.
